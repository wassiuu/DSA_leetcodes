# DSA_leetcodes
# Data Structures & Algorithms Practice

A collection of my solutions to Data Structures and Algorithms problems as I work through LeetCode and strengthen my problem-solving skills.

The goal of this repository is to document my progress, improve my understanding of common DSA patterns, and develop the skills needed to solve technical interview problems efficiently.

## 📚 Topics

I'm currently working through problems involving:

* Arrays & Strings
* Hash Maps & Hash Sets
* Two Pointers
* Sliding Window
* Prefix Sums
* Stacks & Queues
* Linked Lists
* Binary Search
* Trees & Graphs
* Heaps / Priority Queues
* Recursion & Backtracking
* Dynamic Programming

More topics and solutions will be added as I progress.

## 🧠 Approach

For each problem, I focus on:

1. Understanding the problem and constraints
2. Developing a solution before looking at the optimal approach
3. Analyzing time and space complexity
4. Comparing my solution with alternative approaches
5. Recognizing reusable DSA patterns

## 💻 Language

Most solutions are currently written in **Python**.
